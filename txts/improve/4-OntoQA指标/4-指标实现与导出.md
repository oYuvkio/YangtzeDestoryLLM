目标：计算 TBox 结构指标，产出论文用表。


任务：工具化 OntoQA 指标（RR/IR/AR）计算，并输出 CSV/Markdown 表；支持多版本 TBox 批量对比。

[改动点]
1) 新增 tools/ontoqa_metrics.py
   - 输入：--tboxes "p2.json,p3.json,p4.json"（逗号分隔）
   - 计算：
     * C = 类数量
     * SC = 继承（父子）关系数量
     * P = 非继承关系数量（domain-range 类型的谓词）
     * A = 属性数量（value_type 字段）
     * RR = P / (P + SC)
     * IR = SC / C
     * AR = A / C
   - 输出：
     * outputs/ontoqa/metrics.csv（列：model_name,C,SC,P,A,RR,IR,AR）
     * outputs/ontoqa/metrics.md（三线表格式）

[CLI]
python tools/ontoqa_metrics.py \
  --tboxes "outputs/cq_pipeline/final/p2_tbox_init.json,outputs/cq_pipeline/final/p3_tbox_dedup_final.json,outputs/cq_pipeline/final/p4_tbox_enhanced.json" \
  --out-csv "outputs/ontoqa/metrics.csv" \
  --out-md "outputs/ontoqa/metrics.md" \
  --log-file "logs/ontoqa/run.log"

[验收标准]
- CSV/MD 正确导出，RR/IR/AR 合理（非负，分母不为0时有值）
- 日志含每个版本 TBox 的计数详情
