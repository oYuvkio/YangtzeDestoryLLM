目标：生成用途清单，文档（或章节）在 P4（本体增强）与 EVAL（评测池）之间互斥，避免信息泄漏；支持章节级别分流。

任务：实现 manifest 生成与过滤工具，满足论文复现要求的“用途互斥 + 章节过滤 + 可选时间隔离”。

[改动点]
1) 新增 tools/build_manifest.py：
   - 输入：clean 语料 JSONL（含字段至少有 id, source_type, doc_title, rel_path, year, text, topic_label）
   - 输出：data/manifests/purpose_manifest.jsonl，每行：
     {
       "doc_id": "<hash or rel_path>",
       "purpose": ["P4"] 或 ["EVAL"],
       "split_level": "doc" 或 "section",
       "section_hint": "<章节名或空>",
       "rationale": "<打标签原因>"
     }
   - 规则：
     a. source_type in {emergency_plan, gazette_yearbook, regulation, technical_guideline} 且句式含定义词(“是/指/包括/分为/规定/响应级别”) → 倾向 P4
     b. 含具体时间/地点/数值（年份、具体省市、m³/s、亿元、万人等） → 倾向 EVAL
     c. 同一 rel_path 的文档默认 doc-level 互斥；若章节字段可用且章节命中 a/b 冲突，split_level=section，section_hint 填章节名，并给 rationale
     d. 可选时间隔离：--p4_year_max、--eval_year_min（默认 None，不启用）

2) 新增 filters/apply_manifest.py：
   - 功能：根据 manifest 过滤输入 JSONL，输出到指定目录（p4_only.jsonl / eval_only.jsonl），支持 --split-level=doc|section。
   - 若 split_level=section：仅保留 manifest 标记为该用途的章节/段落。

[CLI]
python tools/build_manifest.py \
  --input "data/corpus_for_kg/filtered_ytz_corpus/light_pool_dedup.jsonl" \
  --out "data/manifests/purpose_manifest.jsonl" \
  --p4-year-max 2016 \
  --eval-year-min 2017 \
  --log-file "logs/manifest/build.log" \
  --seed 42

python filters/apply_manifest.py \
  --input "data/corpus_for_kg/filtered_ytz_corpus/light_pool_dedup.jsonl" \
  --manifest "data/manifests/purpose_manifest.jsonl" \
  --purpose "P4" \
  --split-level "doc" \
  --out "data/corpus_for_onto/p4_only.jsonl" \
  --log-file "logs/manifest/apply_p4.log"

python filters/apply_manifest.py \
  --input "data/corpus_for_kg/filtered_ytz_corpus/light_pool_dedup.jsonl" \
  --manifest "data/manifests/purpose_manifest.jsonl" \
  --purpose "EVAL" \
  --split-level "doc" \
  --out "data/corpus_for_kg/eval_only.jsonl" \
  --log-file "logs/manifest/apply_eval.log"

[验收标准]
- 生成的 manifest JSONL 合法，且 P4 与 EVAL 在 doc_id 上互斥（无交集）。
- 支持章节级分流（若输入含章节字段）。
- 日志中打印 P4/EVAL 数量、比例、触发规则计数。
