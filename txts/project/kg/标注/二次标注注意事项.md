这是一个非常务实且必要的步骤。在涉及敏感领域（如政策、政治新闻）时，LLM 的拒答率确实会上升，且这类语料往往包含大量“正确的废话”，对知识图谱的实体关系抽取价值有限，甚至可能引入噪声。

你的决策非常正确：**舍弃无法提取的，并对提取结果进行二次审查（Sanity Check）**。

以下是为你设计的 **“金标数据二次审查 Prompt”**，旨在过滤掉非客观、非事实性或纯政治宣传的内容，确保测试集的纯净度。

---

### 1. 二次审查 Prompt 设计思路

这个 Prompt 的角色是一个 **“数据质量审计员”**。它的任务不是抽取，而是 **“判别”**。

**审查维度（Criteria）：**
1.  **事实密度（Fact Density）**：文本是否包含具体的实体（时间、地点、数值、事件）？如果全是“加强领导、提高认识”等空话，直接丢弃。
2.  **敏感性/合规性（Safety/Compliance）**：是否涉及敏感政治人物、意识形态争论？如果是，丢弃。
3.  **图谱价值（KG Value）**：提取出的三元组是否构建了有意义的知识网络？如果提取出的全是 `(会议, 召开, 北京)` 这种通用废话，丢弃。
4.  **客观性（Objectivity）**：是否是客观陈述？避免主观评论或宣传口号。

---

### 2. Prompt 模板代码

建议在 `prompts.py` 中新增 `GOLD_SANITY_CHECK_PROMPT`。

```python
# ========== 金标数据二次审查 Prompt ==========
GOLD_SANITY_CHECK_PROMPT = """
你是一名严格的**知识图谱数据审计员**。
你的任务是审查一条“黄金标准测试用例”，判断其是否适合用于评估“长江流域水旱灾害知识抽取算法”。

【审查对象】
1. **原始文本**：
{input_text}

2. **已提取的三元组**：
{triples_json}

【审查标准（必须全部满足才能通过）】
1. **事实性（Factual）**：原始文本必须包含具体的灾害事件、水利工程、地理位置、水文数据或具体的应急措施。
   - *反例*：“我们要深入贯彻XX精神，加强防汛抗旱工作。”（纯口号，无事实，**丢弃**）
   - *正例*：“1998年8月，长江沙市水位达到45.22米。”（有具体事实，**保留**）

2. **非敏感性（Non-Sensitive）**：文本不应包含敏感政治人物的非公开活动、意识形态争论或可能触发安全合规问题的敏感词。
   - 如果文本主要内容是政治宣传或会议通稿，且缺乏具体业务数据，**丢弃**。

3. **图谱价值（KG Value）**：提取出的三元组必须具有领域知识价值。
   - 如果三元组仅包含 `(会议, 召开, 日期)` 或 `(文件, 发布, 部门)` 等通用行政信息，而缺乏水利专业内容，**丢弃**。

4. **完整性（Completeness）**：提取的三元组没有明显的逻辑错误或乱码。

【输出格式】
请直接输出 JSON，不要包含 Markdown 标记：

{{
  "decision": "KEEP" 或 "DISCARD",
  "reason": "简短说明原因（50字以内）",
  "fact_score": 0-10 (事实密度评分，10分最高),
  "risk_flag": true/false (是否涉及敏感/政治内容)
}}
"""
```

### 3. 配套 Python 脚本 (`audit_gold_standard.py`)

你需要写一个脚本来批量跑这个 Prompt。

```python
import json
from kg.llm_core import LLMFactory
from prompts import GOLD_SANITY_CHECK_PROMPT

def audit_gold_data(gold_file_path, output_path):
    # 1. 加载已生成的金标数据
    with open(gold_file_path, 'r', encoding='utf-8') as f:
        gold_data = json.load(f)  # 假设是 list of dict

    llm = LLMFactory.create(config={...}) # 使用你的配置
    
    clean_data = []
    discarded_log = []

    print(f"开始审查 {len(gold_data)} 条数据...")

    for item in gold_data:
        text = item['text']
        triples = item['gold_triples']
        
        # 构造 Prompt
        prompt = GOLD_SANITY_CHECK_PROMPT.format(
            input_text=text,
            triples_json=json.dumps(triples, ensure_ascii=False)
        )

        # 调用 LLM
        try:
            response = llm.chat(prompt)
            result = json.loads(response) # 记得加 try-catch 处理 JSON 解析
            
            if result['decision'] == 'KEEP':
                item['audit_info'] = result # 可选：保留审查元数据
                clean_data.append(item)
                print(f"[KEEP] {text[:20]}... (Score: {result['fact_score']})")
            else:
                discarded_log.append({
                    "text": text[:50],
                    "reason": result['reason']
                })
                print(f"[DISCARD] {text[:20]}... Reason: {result['reason']}")
                
        except Exception as e:
            print(f"[ERROR] 处理失败: {e}")

    # 保存清洗后的数据
    with open(output_path, 'w', encoding='utf-8') as f:
        json.dump(clean_data, f, ensure_ascii=False, indent=2)
        
    print(f"审查完成。保留: {len(clean_data)}, 丢弃: {len(discarded_log)}")
    
    # 保存丢弃日志（可选）
    with open(output_path + ".discarded.json", 'w', encoding='utf-8') as f:
        json.dump(discarded_log, f, ensure_ascii=False, indent=2)

if __name__ == "__main__":
    audit_gold_data("data/gold_standard_raw.json", "data/gold_standard_clean.json")
```
